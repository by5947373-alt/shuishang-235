# 照片

**建議直接從後台上傳**（後台 →「圖片」分頁），17 個欄位都在那裡，
上傳就生效、不用改程式碼也不用重新部署。

這個資料夾是給「隨程式碼一起進 git 的預設圖」用的。放在這裡的圖會被
後台上傳的同名圖蓋掉，而且後台刪不掉它們。

檔名固定，放進來**重新建置**就會生效，不用改任何程式碼。
（線上是每次部署時重新產生，所以 push 上去就會接上。）

沒放的欄位不會發 404 —— 建置時會檢查檔案在不在，不在就整個不輸出。
沒放的欄位不會破圖——會顯示一片有斜紋的蜜桃色底，看起來是設計過的，不是缺圖。

| 檔名 | 用在哪 | 建議尺寸 | 拍什麼 |
|---|---|---|---|
| `sp-routes.jpg` | 首頁「特別企劃 #01」散策路線卡 | 1200×675（16:9） | 綠色隧道、鐵道、田間小路 |
| `sp-map.jpg`  | 首頁「特別企劃 #02」地圖卡 | 1200×675（16:9） | 田景、鐵道、街區的遠景 |
| `hero-taste.jpg` | 品味頁的整面底圖 | 1600×900 以上 | 店面、街景、food 的環境照 |
| `hero-culture.jpg` | 回歸頁的整面底圖 | 1600×900 以上 | 糖廠、鐵道、太陽館的遠景 |
| `hero-grow.jpg` | 生長頁的整面底圖 | 1600×900 以上 | 田、溫室、採收的畫面 |

分類頁的底圖會被打淡到 18%（上面蓋一層奶油色），所以**不要挑細節很重要的照片**，
選色調單純、構圖鬆的環境照即可 —— 它是背景不是主角。

## 給的時候注意

- **橫幅 16:9**，主體放中間（版面會裁掉上下或左右）。
- **JPG，長邊 1200–1600px、壓到 300KB 以內**。這是純靜態站，圖片大小直接等於載入速度。
- 有人臉的話要有被拍者同意，尤其小孩。

### 單店頁的底圖

每家店一張，檔名就是頁面名：`taste-01.jpg`、`taste-02.jpg` …… `grow-04.jpg`
（對應 taste-01.html 等）。跟分類頁一樣會被打淡，挑環境照就好。

## 還沒開的欄位

店家的「主視覺」照片（放在卡片裡當主角、不是打淡的底圖）還沒做。
等你給的圖到齊，我看實際有哪些素材再決定要一家一張還是做成相簿，
那會動到 `src/content.json` 的結構。
